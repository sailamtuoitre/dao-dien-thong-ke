# Quản lý Thực tập — UC11 / UC12

Ứng dụng frontend React + TypeScript cho hai Use Case:

- **UC11** — Chấm điểm sinh viên thực tập (Giảng viên)
- **UC12** — Thống kê kết quả thực tập (Quản trị viên)

## Cài đặt

```bash
npm install
```

## Chạy

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Công nghệ

- React 18 + TypeScript
- Vite
- React Router DOM
